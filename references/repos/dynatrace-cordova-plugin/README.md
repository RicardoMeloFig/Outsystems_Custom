# Dynatrace Cordova plugin wrapper for OutSystems

This plugin is based on the code published by Dynatrace as an NPM package at [this location](https://www.npmjs.com/package/@dynatrace/cordova-plugin).
It gives you the ability to use the Dynatrace instrumentation in your hybrid application.

**For development workflow, setup, and coding standards, see [CONTRIBUTING.md](./CONTRIBUTING.md).**

## Dynatrace Cordova plugin version

This is based on @dynatrace/cordova-plugin version 2.335.1.

## Agent Versions

This agent versions are configured in this plugin:
- Android Agent: 8.335.1.1001
- iOS Agent: 8.335.1.1001

## MABS Version
This plugin uses MABS version 11.

## Maintaining This Wrapper

This repository wraps the official `@dynatrace/cordova-plugin` and adds OutSystems-specific functionality. For complete instructions on updating to newer upstream versions, including modifying native code and adding OutSystems customizations, see [CONTRIBUTING.md - Updating the Plugin Wrapper](./CONTRIBUTING.md#updating-the-plugin-wrapper).
